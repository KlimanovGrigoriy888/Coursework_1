# Проект coursework-1

## Описание:

Проект coursework-1 - это приложение на Python которое обрабатывает информацию банковских операций с целью преобразования в готовый вид в зависимости от используемой функции.
## Установка:

1. Клонируйте репозиторий из PyCharm:
```
---git clone https://github.com/KlimanovGrigoriy888/Coursework_1.git
```
2. Проверьте имеется ли у вас менеджер зависимостей poetry выполнив команду:
```
poetry --version
```
3. Если в PyCharm нет poetry установите Poetry через команду:
```
pip install poetry
```
4. Для установки зависимостей проекта из файла pyproject.toml исполните команду:
```
poetry install
```
5. Для работы фреймворка pytest и pytest-cov необходимо в PyCharm добавить эти фреймворки. Наберите команду в терминале:
```
poetry add --group dev pytest pytest-cov
```
6. Для работы с URL запросом курса валют на "https://api.twelvedata.com" 
необходимо:
* Зайти на сайт twelvedata быстрый старт: https://twelvedata.com/docs/introduction/quickstart и зарегистрироваться на данном ресурсе
и получить свой API_KEY.
* Для работы функции requests.request() программы settings_for_api() в модуле utils.py для запроса курса вылют и акций
необходимо в файле .env_template вписать свой ключ в API_KEY и переименовать .env_template в .env
* Для того что бы программа settings_for_api() могла получать конфиденциальный API_KEY из файла .ven для запроса
на "https://api.twelvedata.com" по твоему ключу API_KEY, необходимо установить библиотеку python_dotenv. Для этого наберите
команду в терминале:
```
poetry add python-dotenv
```
* Так же для работы функции requests.request() необходимо установить библиотеки requests для этого наберите команду 
в терминале:
```
potery add requests
```
* Для работы с библиотекой pandas  открытия файлов excel необходимо установить библиотеку с помошью команд 
```
poetry add pandas, openpyxl
```


## Использование:

1. Клонируйте код в PyCharm.

2. В модуле views.py реализованна функция для обработки банковских транзакций главная for_main() для веб-страницы главная 
которая принимает на вход строку с датой и временем в формате YYYY-MM-DD HH:MM:SS,
возвращает JSON-ответ со следующими данными:
* Приветствие в формате "???", где ??? — «Доброе утро» / «Добрый день» / «Добрый вечер» / «Доброй ночи» в зависимости от текущего времени.
По каждой карте:
* последние 4 цифры карты;
* общая сумма расходов;
* кешбэк (1 рубль на каждые 100 рублей).
* Топ-5 транзакций по сумме платежа.
* Курс валют.
* Стоимость акций из S&P500. 
   
3. В модуле utils.py реализованны функции необходимые для работы функции for_main() модуле views.py и функций services.py:
* Функция time_of_day() определяет текущее время и в зависимости от времени дня возвращает строку в виде «Доброе утро» / «Добрый день» / «Добрый вечер» / «Доброй ночи».
* Функция read_json_file() принимает путь до .json файла и возвращает список словарей, используется в функции settings_for_api()
для получения списка в JSON формате данных для запроса по API.
* Функция read_excel() принимает путь до .xlsx файла финансовых операций, возвращает список словарей с транзакциями. Используется как дополнительная функция для работы функций в модуле services.py.
* Функция read_excel_to_df() принимает путь до .xlsx файла финансовых операций, возвращает финансовые операции в формате DataFram.
* Функция transformed_date() принимает строку в формате DD.MM.YYYY HH:MM:SS и возвращает "YYYY.MM.DD HH:MM:SS" для корректного сравнения строк даты в DataFrame.
* Функция get_range_data() принимает строку в формате YYYY-MM-DD HH:MM:SS возвращает диапазон: от начала месяца до указанной даты
в формате YYYY.MM.DD HH:MM:SS" в виде словаря {"start_data": start_data, "end_data": end_data}.
* Вспомогательная функция clean_amount() принимает строку с цифровым значение или цифры и очищает значение суммы: убирает запятые,
* лишние пробелы по краям и конвертирует во float.
* Функция cart_agg_for_main() принимает DataFrame с финансовыми операциями, даты начала и конца в виде строки и фильтрует по диапазону даты,
производит агрегацию по каждому номеру карты и по каждой карте возвращает общую сумму расходов и кешбэк (1 рубль на каждые 100 рублей) и топ 5 транзакций по сумме платежа.
* Функция settings_for_api() принимает путь до .json файла с установками для запроса по API, возвращает необходимую строку для API запроса по url адресу "https://api.twelvedata.com" в необходимом формате.
* Функция get_currency_and_stocks() обращается к внешнему API для получения текущего курса валют по отношению к рублю по заданному формату из файла user_settings.json, возвращает json данные о курсах акций и курсах валют.

4. В модуле services.py реализованны функции обработки банковских транзакций для раздела сервисы.
* Функция cashback_benefit() Функция принимает на вход список словарей с транзакциями, анализирует список транзакций и подсчитывает потенциальный 
кешбэк по категориям за указанный год и месяц, принимает на вход data - данные с транзакциями, year — год и month — месяц, за который
проводится анализ. Возвращает JSON с анализом, сколько на каждой категории можно заработать кешбэка.
* Функция investment_bank() принимает на вход:
     month — месяц в формате 'YYYY-MM', для которого рассчитывается отложенная сумма.
     transactions — список словарей, содержащий информацию о транзакциях, в которых содержатся следующие поля.
     limit — предел, до которого нужно округлять суммы операций (целое число).
     Возвращает сумму, которую удалось бы отложить в «Инвесткопилку».
* Функция simple_search() принимает на вход строку для поиска search_data и transactions — список словарей банковских транзакций, содержащий 
информацию о транзакциях, возвращает JSON-ответ со всеми транзакциями, содержащими запрос в описании или категории.
* Функция search_with_phone_number() принимает на вход список словарей, содержащий информацию о банковских транзакциях,
возвращает JSON-ответ со всеми транзакциями, содержащими в описании мобильные номера.

5. В модуле reports.py реализованны функции обработки банковских транзакций для формирования отчетов.
* Написан декоратор log_record() для функций модуля reports.py. Декоратор для функции, записывает в файл результат,
который возвращает функция, записывает его в файл record_file.txt:
Если принимаемая функция выполнилась без исключений в лог записывается результат работы функции
Если при исполнении функции возникло исключение в лог записывается сообщение о выпавшем исключении декорируемой функции.
* Дополнительная функция get_range_data_for_reports() принимает указанную дату в формате строки "dd.mm.YYYY HH:MM:SS" возвращает диапазон:
от трех месяцев назад до указанной даты в формате datetime в виде start_date, end_date.
* Функция spending_by_category() принимает на вход: датафрейм с транзакциями, название категории, опциональную дату в формате
DD.MM.YYYY HH:MM:SS. Если дата не передана, то берется текущая дата. Функция возвращает траты по заданной категории
за последние три месяца (от переданной даты).
* Функция spending_by_weekday() принимает на вход: датафрейм с транзакциями, опциональную дату. Если дата не передана,
то берется текущая дата. Функция возвращает средние траты в каждый из дней недели за последние три месяца (от переданной даты).

## Тестирование:

1. В пакете tests реализованны функции тестирования всех функций пакета src. Тест покрывает 90% кода функций.
2. Для просмотра тестов создан файл htmlcov в корне проекта.
4. Для выполнения и просмотра результата всех выполненных тестов необходимо написать команду терминале:
```
poetry run pytest --cov

```
5. Для формирования отчета в HTML формате и создания файла htmlcov, необходимо написать команду в терминале:
```
pytest --cov=src --cov-report=html

```
