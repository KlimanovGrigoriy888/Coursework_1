# Проект Homework_10.1

## Описание:

Проект Homework_10.1 - это приложение на Python которое обрабатывает информацию банковских реквизитов с целью преобразования в готовый вид-маску, для отфильтровывания списков словарей с id по ключам 'state' и 'data'. В настоящее время проект в разработке и не имеет оконченный вид т.е. реализованную конечную функцию. 

## Установка:

1. Клонируйте репозиторий из PyCharm:
```
---git clone https://github.com/KlimanovGrigoriy888/Homework_module_10.1.git
```
2. Проверьте имеется ли у вас менеджер зависимостей poetry выполнив команду:
```
poetry --version
```
3. Если в PyCharm нет poetry установите Poetry через команду:
```
pip install poetry
```
4. Для установки зависимостей проекта из файла pyproject.toml исполните команду:
```
poetry install
```
5. Для работы фреймворка pytest и pytest-cov необходимо в PyCharm добавить эти фреймворки. Наберите команду в терминале:
```
poetry add --group dev pytest pytest-cov
```
6. Для работы с URL запросом курса валют на "https://api.apilayer.com/exchangerates_data/latest?symbols=&base=RUB" 
необходимо:
* Зайти на Exchange Rates Data API: https://apilayer.com/exchangerates_data-api и зарегистрироваться на данном ресурсе
и получить свой API_KEY.
* Для работы функции requests.request() программы get_course_curensy() в модуле external_api.py для запроса курса вылют
необходимо в файле .env.example вписать свой ключ в API_KEY и переименовать .env.example в .env
* Для того что бы программа get_course_curensy() могла получать конфиденциальный API_KEY из файла .ven для запроса
на Exchange Rates Data API по твоему ключу API_KEY, необходимо установить библиотеку python_dotenv. Для этого наберите
команду в терминале:
```
poetry add python-dotenv
```
* Так же для работы функции requests.request() необходимо установить библиотеки requests для этого наберите команду 
в терминале:
```
potery add requests
```

## Использование:

1. Клонируйте код в PyCharm, так как проект не имеет конечной функции, то здесь опишу реализованные функции в модулях.
2. В модуле masks.py реализованны функции обработки номера карты 'get_mask_card_number'и счета 'get_mask_account' c выводом готовой маски этих номеров, типа: Visa Platinum 7000 XX** **** XXXX, Счет **XXXX..
3. В модуле widget.py реализованны функции: Первая функция 'mask_account_card' которая принемает название и номер счета или карты и используя функцию из модуля masks.py для обработки номера карты или счета в маску но при этом оставляет название карты или 'счет'. Так же в этом модуле реализованна функция 'get_date' которая принимает строку в формате "2024-03-11T02:26:18.671407" и возвращает "ДД.ММ.ГГГГ"
4. В модуле processing.py реализованны функции обработки списка словарей. Первая функция filter_by_state которая по вводимому ключу сортировки 'state' (по умолчанию'EXECUTED') отсортировывает список по этому ключу. И вторя функция sort_by_date которая по ключу key_sort отсортировывает список по дате в обратном порядке если key_sort = True так же по умолчанию равен True и в прямом порядке если key_sort = False.
5. В модуле generators.py реализованны функции обработки списка словарей банковских транзакций и генерация номеров карт, все функции возвращают генераторный объект.
* Первая функция filter_by_currency принимает на вход и отфильтровывает банковские транзакции по названию валюты и возвращает транзакции по названной валюте.
* Вторая функция transaction_descriptions также принимает на вход банковские транзакции и возвращает описание каждой операции из банковских транзакций по очереди.
* Третья функция card_number_generator является генератором номеров банковских карт в заданном на входе функции диапазоне начала и окончания номеров карт.
6. В модуле decorators.py реализована функция декоратор @log(Filename), используя его для функции он возвращает лог и записывает его в файл Filename в следующем порядке: 
* Если принимаемая функция выполнилась без исключений в лог записывается сообщение "my_function ok"
* Если при исполнении функции возникло исключение в лог записывается сообщение о выпавшем исключении.
7. В модуле external_api реализованна get_course_currency() обращается к внешнему API для получения текущего курса валют по отношению к рублю.
 Для настройки ее работы в проекте смотри раздел установка пункт "6".
8. В модуле utils реализованны функции:
* get_transactions() которая принимает на вход путь до JSON-файла operation.json в файле data c банковскими транзакциями и возвращает список словарей с данными о финансовых транзакциях.
* get_amount_transactions() которая принимает на вход одну банковскую транзакцию с денежной суммой и видом валюты и возвращает сумму этой транзакции (amount) в рублях, тип данных —
    float. Если транзакция была в USD или EUR, происходит обращение к функции конвертации в модуле external_api для получения текущего курса валют и конвертации суммы операции в рубли
9. В модуле external_files реализованны функции которые принимают фйлы с банковскими транзакциями из директории /data и должны иметь названия transaction.csv и transactions_excel.xlsx:
* read_csv() которая принимает путь до .csv файла финансовых операций, возвращает список словарей с транзакциями.
* read_excel() которая принимает путь до .xlsx файла финансовых операций, возвращает список словарей с транзакциями.
10. В модуле processing_bank реализованны функции которые принимают список словарей с банковскими транзакциями:
* Функция process_bank_search() принимает список словарей с данными о банковских операциях и строку поиска, возвращает список словарей, у которых в описании есть данная строка в 'description'.
* Функция process_bank_operations() принимает список словарей с данными о банковских операциях и список категорий операций, возвращает словарь, в котором ключи — это названия категорий, а значения — это количество операций в каждой категории.
11. В модуле main.py собрана программа из функций модуля src. Задача этой программы состоит в обработке банковских транзакций из файлов в папке data, далее через интерфейс ввода для пользователя поочереди предлагает:
* сделать выбор фильтрации по типу файла в папке data
* сделать выбор фильтрации операций по статусу операции
* сделать выбор сортировку транзакций по дате
* если выбрали сортировку транзакций по дате, то далее предложит сделать выбор по возрастанию или по убыванию даты
* сделать выборку по рублевым транзакциям или нет
* сделать фильтрацию по слову в транзакции.
Возвращает список выбранных транзакций с информацией с датой, виду транзакции, с масками счета или карты и суммой.

## Тестирование:

1. В пакете tests реализованны функции тестирования всех функций пакета src. Тест покрывает 90% кода функций.
2. Для просмотра тестов создан файл htmlcov в корне проекта.
4. Для выполнения и просмотра результата всех выполненных тестов необходимо написать команду терминале:
```
poetry run pytest --cov

```
5. Для формирования отчета в HTML формате и создания файла htmlcov, необходимо написать команду в терминале:
```
pytest --cov=src --cov-report=html

```
6. Тесты для следующих функций: get_course_currency() в модуле external_api и get_transactions(), get_amount_transactions() в мо написаны с помощью 
 фикстуры patch из библиотеки unittest.mock для теста программ с помощью обманки-заглушки для имитации работы функций которые получают внешние данные по HTTP запросу через API
 или которые обрабатывает информацию из файла.
